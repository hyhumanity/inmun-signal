# 느린 우체통

인문과학대학 학생회끼리 주고받는 롤링페이퍼. 지금 쓴 편지는 정해진 날 한꺼번에 열립니다.

- 주소: https://hyhumanity.github.io/inmun-signal/mailbox/
- 여는 날 전에는 누가 몇 통 받았는지만 보이고, 내용은 서버에서 아예 보내지 않습니다.
- 학생회 암호를 아는 사람만 들어올 수 있습니다.
- 우체통이 열린 뒤에는 암호를 아는 학생회 모두가 모든 편지를 읽을 수 있습니다 (종이 롤링페이퍼처럼).

## 설정 (약 10분)

인문 신호등과 **다른 새 시트**로 만드세요. 민원과 편지가 섞이지 않게 하기 위해서입니다.

1. 학생회 구글 계정으로 [새 스프레드시트](https://sheets.new) → 이름 `느린 우체통`
2. **확장 프로그램 → Apps Script** → 기존 코드를 지우고 `mailbox/apps-script/Code.gs` 내용을 붙여넣기
3. 맨 위 두 줄을 **편집기 안에서** 바꾸고 저장
   - `PASSCODE`: 학생회 암호 (예: `'inmun2026'`)
   - `REVEAL_AT`: 여는 날과 시각 (예: 종강총회 `'2026-12-19T18:00:00+09:00'`)
   - 이 두 값은 GitHub에 올리지 마세요. 저장소는 공개라 누구나 볼 수 있습니다.
4. 함수 선택 칸에서 `setup` → **▶ 실행** → 권한 허용
5. 시트의 `멤버` 탭 A열에 집행부원 이름을 한 칸에 한 명씩 적기
6. **배포 → 새 배포 → 웹 앱**, 실행 사용자 **나**, 액세스 **모든 사용자** → 배포 → 웹 앱 URL 복사
7. `mailbox/config.js`의 `scriptUrl`에 그 주소를 넣기

## 운영

- 멤버를 추가·삭제하려면 `멤버` 탭만 고치면 됩니다. 재배포는 필요 없습니다.
- 여는 날을 바꾸려면 `REVEAL_AT`을 고친 뒤 **배포 관리 → 수정 → 새 버전 → 배포**를 합니다.
- 부적절한 편지는 `편지` 탭에서 행을 지우면 사라집니다.
- 편지 내용과 보낸 사람은 시트에 봉인된 채 저장됩니다. 시트를 열어도 `SEAL:…`로만 보입니다.
- 봉인 기능을 넣기 전에 들어온 편지는 함수 선택 칸에서 `sealExisting` → **▶ 실행**으로 한 번 봉인하세요.
- 여는 날 이후 시트에 원문을 남기고 싶으면 `unsealAll`을 실행하세요. 여는 날 전에는 동작하지 않습니다.
- 봉인 열쇠는 **프로젝트 설정 → 스크립트 속성**의 `SEAL_KEY`에 있습니다. 지우면 편지를 풀 수 없으니 건드리지 마세요.
- 학생회 구글 계정 자체에 로그인할 수 있는 사람은 마음먹으면 열쇠를 찾을 수 있습니다. 계정 비밀번호를 아는 사람을 최소로 해주세요.
