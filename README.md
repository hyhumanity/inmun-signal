# 인문 신호등

인문과학대학 학생회 민원 트래커. 학우는 로그인 없이 민원을 접수하고, 처리 단계를 누구나 확인할 수 있습니다.

- 웹사이트: GitHub Pages (`index.html`, `config.js`)
- 저장소: 학생회 구글 시트 (`apps-script/Code.gs`가 시트와 웹사이트를 연결)
- 관리: 학생회는 구글 시트에서 `처리단계`, `담당국`, `답변` 칸만 고치면 웹사이트에 1분 안에 반영

## 1. 구글 시트 만들기 (약 5분)

1. 학생회 구글 계정으로 [새 스프레드시트](https://sheets.new)를 만들고 이름을 `인문 신호등 민원`으로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기존 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣은 뒤 저장(디스크 아이콘)합니다.
4. 위쪽 함수 선택 칸에서 `setup`을 고르고 **▶ 실행**을 누릅니다.
   - "권한 검토 필요" 창이 뜨면 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**. 학생회 계정이 직접 만든 스크립트라 이렇게 표시되는 것입니다.
5. 시트로 돌아가면 `민원` 탭과 머리글이 생겨 있습니다.

## 2. 웹 앱으로 배포하기

1. Apps Script 화면 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴에서 유형 **웹 앱** 선택
3. 실행 사용자: **나**, 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사

## 3. 웹사이트에 주소 넣기

`config.js`의 `scriptUrl: ""` 따옴표 안에 위 주소를 붙여넣고 저장(커밋)합니다. 비워두면 예시 데이터로 보이는 미리보기 모드입니다.

## 4. GitHub Pages 켜기

저장소 **Settings → Pages → Branch: main / (root) → Save**. 1~2분 뒤 `https://hyhumanity.github.io/inmun-signal/`에서 열립니다.

## 학생회 운영 방법

| 시트 칸 | 하는 일 |
|---|---|
| 처리단계 | 접수 → 담당 배정 → 검토 중 → 학교 전달 → 완료 / 처리 불가 중에서 고르기. 바꾸는 순간 날짜가 자동 기록됩니다. |
| 담당국 | 회장단, 사무국, 기획국, 복지국, 홍보국, 대외협력국 중에서 고르기 |
| 답변 | 학우에게 공개되는 답변. 처리 불가일 때는 사유를 꼭 적어주세요. |
| 비공개요청 | `Y`면 웹사이트 목록에서 숨김 (학우가 비공개로 접수하면 자동으로 `Y`) |

- 부적절한 글은 `비공개요청`을 `Y`로 바꾸거나 행을 삭제하면 됩니다.
- `단계기록`, `공감` 칸은 자동으로 채워지니 직접 고치지 마세요.
- 코드를 고쳤다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 주소는 그대로 유지됩니다.

## 처리 원칙 숫자 바꾸기

`config.js`에서 `firstReplyDays`(1차 답변 기한), `resultDays`(결과 공개 기한), `likeGoal`(간담회 안건 공감 수)을 고치면 됩니다.

## 알아둘 점

- 공감은 브라우저당 한 번으로 제한되지만, 다른 기기나 브라우저로는 다시 누를 수 있습니다.
- 도배 방지를 위해 10분에 전체 30건까지만 접수됩니다 (`Code.gs`의 `MAX_SUBMITS_PER_10MIN`).
- 시트 자체는 학생회 계정에만 있고 공개되지 않습니다. 웹사이트에는 공개 가능한 칸만 전달됩니다.
